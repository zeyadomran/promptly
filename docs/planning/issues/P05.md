# P05: Persist settings and broadcast immediate preference changes

Keep every preference consistent across windows and launches.

## Scope

- Define defaults for theme/system, compact startup mode, pin=false, normalization=true, toast=true, Shift double-tap/300 ms, show/hide Alt+Space or Option+Space, and optional pin shortcut.
- Persist login/tray/dock options, per-mode bounds, onboarding completion, shortcut configuration, and validated 150–600 ms timing.
- Represent hide-after-copy as an explicit override or automatic default: auto hides when unpinned and stays open when pinned; explicit user choices remain stable.
- Apply through typed services and notify all windows immediately. Roll back failed OS operations and leave the last working preference active.
- Use one persisted pin state for title-bar and Appearance controls; distinguish remembered per-mode geometry from preferred startup mode.

## Acceptance criteria

- [ ] No Save button is required; valid changes survive restart.
- [ ] Invalid values do not corrupt preferences; failed side effects show a useful error.
- [ ] Open main/settings/toast renderers converge on updated theme and preferences.

## Verification

Defaults/migration/validation tests and multi-window update and failed-operation rollback tests.
