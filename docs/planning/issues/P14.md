# [P14] Implement substring search, filter syntax, sorting, and paginated queries

> Current scope (2026-10-02): Windows x64 only. macOS is deferred and is not a dependency or release gate. #55 removes its implementation. Use minimal functional service tests, one canonical test per flow; native/UI qualification remains manual. This supersedes older cross-platform acceptance text and historical comments.

Return correct, responsive search results for at least 10,000 snippets.

## Scope

- Parse tag: and from: alongside free text; define quoted names, incomplete tokens, literal punctuation, unknown filters, and escaping without exposing raw SQL/FTS syntax.
- Use case-insensitive substring semantics, AND across selected tags and tag: tokens, intersection with source/free text, All reset, and Regular Untagged.
- Evaluate FTS5 trigram plus a correct short-query path or an in-memory index; ordinary token FTS alone does not fulfill substring matching. Verify Unicode behavior and 1–2-character searches.
- Implement all four stable sorts, counts, pagination, stale-response protection, and shared match ranges for safe renderer highlighting.
- Preserve correct large-library results and stale-response protection; performance measurements and budgets are skipped for this pass.

## Acceptance criteria

- [ ] Substring, punctuation, Unicode, AND-tag intersection, Untagged, all sorts, and combined syntax have documented correct results.
- [ ] Capture/edit/tag/delete/import changes invalidate the index and counts consistently.
- [ ] Short/common/no-match/Unicode queries and rapid input retain correct current results without stale responses; no timing benchmark gates this pass.

## Verification

Extend the existing canonical public functional service flow only where needed; keep real internal services/storage and fake external OS/time boundaries. Run strict types, ESLint, Prettier, functional tests and Windows packaging. UI, native delivery, NVDA and distribution requirements are manual Windows release checks where relevant. Performance measurements and budgets are skipped for this pass. No automated GUI/E2E suite, duplicate flow tests, stress gates or new test infrastructure.
