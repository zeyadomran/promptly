# P02: Define domain contracts and a secure typed IPC bridge

Give React narrow, validated access to desktop operations without exposing privileged APIs.

## Scope

- Define Snippet, Tag, Settings, CaptureResult, paginated search DTOs, typed errors, and change events, with runtime validation at process boundaries.
- Expose named operations through contextBridge; prohibit raw ipcRenderer, arbitrary channels, filesystem paths, and shell commands from the renderer.
- Enable context isolation, renderer sandboxing, nodeIntegration=false, restrictive CSP, local bundled content, sender validation, and controlled navigation/external links.
- Provide subscribe/unsubscribe lifecycle and revisioned change notifications; renderers refetch authoritative data and reject stale search responses.

## Acceptance criteria

- [ ] Malformed requests and unauthorized senders are rejected.
- [ ] A script-shaped snippet is rendered as text and cannot execute.
- [ ] Multiple windows receive updates without duplicate listeners; closing a window disposes subscriptions.

## Verification

Extend the canonical public functional service flow where necessary; run strict checks and Windows packaging. UI/native release qualification is manual.
