# P08: Implement macOS selection capture, permissions, and source app identity

Read selected text on macOS without taking focus or requiring clipboard mutation on the preferred path.

## Scope

- Implement the selected AX/native adapter; record frontmost app identity before any Promptly window operation.
- Read selected text with bounded execution and typed results: success, empty, unsupported, denied, timed out, and protected input.
- Expose Accessibility status and System Settings navigation; handle permission revocation and any additional permission actually required by the selected hook.
- Expose source activation only from validated OS application identity; never execute commands derived from snippet text.

## Acceptance criteria

- [ ] Supported editors, browsers, and terminals return complete selected text with source metadata.
- [ ] Denied/revoked permission does not crash or trigger unsafe fallback.
- [ ] The frontmost application and its selection remain undisturbed.

## Verification

macOS native integration matrix, permission grant/revoke cycles, Unicode/multiline selection, and focus checks.
