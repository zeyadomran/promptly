# P27: Audit design fidelity, keyboard accessibility, and assistive technology

Verify the complete interface against the supplied designs and accessible behavior.

## Scope

- Compare all ten supplied screenshots: four onboarding, compact light/dark, regular light/dark, wide/narrow settings; also cover new Settings subsections using the same tokens.
- Check 4.5:1 text contrast, visible focus, icon labels/tooltips, dialogs, tag dots with text alternatives, OS key labels, reduced motion, and high DPI.
- Verify virtualized list roles/active-descendant behavior, selection independent of copy, focus return, screen-reader announcements, and complete keyboard flows.
- Test VoiceOver and NVDA on real systems; record intentional Windows chrome and accessibility-driven differences from reference pixels.

## Acceptance criteria

- [ ] All reference screens have reviewed comparison artifacts and unresolved differences are filed.
- [ ] No critical keyboard traps, inaccessible icon controls, or unlabeled overlays remain.
- [ ] Settings remains usable around 640 px and with enlarged text; light/dark highlights retain contrast.

## Verification

Automated accessibility scan plus manual keyboard, VoiceOver/NVDA, contrast measurement, and screenshot review.
