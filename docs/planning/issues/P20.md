# P20: Build responsive settings, general preferences, and appearance controls

Provide a reusable responsive shell for all five settings sections.

## Scope

- Implement side navigation at >=640 px and horizontally scrollable tabs below 640 px; stack labels/descriptions and controls while keeping switch rows inline.
- Create separate SettingsWindow, SettingsNavigation, SettingsSection, SettingsRow, GeneralSettings, and AppearanceSettings files; mount Tags, Shortcuts, and Storage sections through clear feature entrypoints.
- Wire launch at login, tray visibility, macOS Dock visibility, hide-after-copy override/default, startup size mode, theme, and pin to immediate settings services.
- Provide platform-specific visibility and permission status; ensure a working way to reopen Promptly before hiding tray/Dock routes.
- Handle rejected native preference changes with inline errors and rollback, without a Save button.

## Acceptance criteria

- [x] 639/640 px breakpoint behavior matches reference layouts and keyboard focus survives resizing.
- [ ] Every listed General/Appearance preference persists and takes effect immediately.
- [ ] macOS-only controls are absent on Windows; close/back returns to the expected window.
