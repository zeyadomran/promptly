# P15: Build the compact library with virtualized snippet rows

Deliver the default 440 px browsing surface using shared list state and components.

## Scope

- Compose the title bar, autofocus search, horizontal tag chips with All and create affordance, virtualized list, and count/pin footer.
- Create separate reusable row, tag-dot group, metadata, copy status, search, and empty-state files; compact layout uses two-line monospace clamps.
- Keep selection by snippet ID across refreshes and ensure keyboard-selected rows stay mounted/in view; provide clear no-selection behavior.
- Render safe highlight ranges, nullable source metadata, no snippets and no results states, and a compact accessible sort control consistent with the design system.
- Wire row click/Enter copy and tag creation through shared command interfaces delivered by dependent integration work; completion of the release tracker requires those integrations.

## Acceptance criteria

- [ ] Light and dark layouts match screenshots without horizontal window overflow.
- [ ] 10k snippets scroll smoothly with bounded mounted rows and stable selection.
- [ ] Counts, pin status, no-results reset, and the configured-shortcut empty-state copy are correct.

## Verification

Component interaction tests for filtering/selection/virtualization and visual comparisons at 440 px and minimum height.
