# P26: Package macOS and Windows installers with native modules and signing support

Produce installable offline builds whose native features work outside development.

## Scope

- Choose and document minimum OS versions and release architectures after the native spike; target macOS arm64/x64 and Windows x64, with Windows arm64 deferred unless validated.
- Configure Forge installers, app identity/icons, native ABI rebuilds/helper bundling, ASAR exclusions, and locally bundled fonts/assets.
- Add macOS signing/notarization and Windows signing configuration using supplied CI secrets; unsigned artifacts must be clearly development-only when credentials are unavailable.
- Define clean install/upgrade/uninstall behavior that preserves the user database on upgrade and avoids unexpected data removal; include licenses.
- Stage artifacts and manual release workflow; no cloud updater, telemetry, or auto-publish feature is required for v1.

## Acceptance criteria

- [ ] Packaged apps launch and capture/search/copy with no dev server or network dependency.
- [ ] Native permissions attach to the actual packaged app identity, and helpers/modules load on each supported architecture.
- [ ] Signing/notarization status and any credential blockers are explicit; unsigned test builds are not described as production-ready.

## Verification

Clean-machine install/upgrade smoke, native module load, offline start, signatures/notarization verification when credentials exist, and database preservation.
