# [P26] Package Windows installers with native modules

> Current scope (2026-10-02): Windows x64 only. macOS is deferred and is not a dependency or release gate. #55 removes its implementation. Use minimal functional service tests, one canonical test per flow; native/UI qualification remains manual. This supersedes older cross-platform acceptance text and historical comments.

Produce installable offline builds whose native features work outside development.

## Scope

- Choose and document minimum OS versions and release architectures after the native spike; target Windows x64, with Windows arm64 deferred unless validated.
- Configure Forge installers, app identity/icons, native ABI rebuilds/helper bundling, ASAR exclusions, and locally bundled fonts/assets.
- Produce clearly labeled unsigned development artifacts. Signing credentials and release signing are outside current authorization; no notarization workflow is required.
- Define clean install/upgrade/uninstall behavior that preserves the user database on upgrade and avoids unexpected data removal; include licenses.
- Stage artifacts and manual release workflow; no cloud updater, telemetry, or auto-publish feature is required for v1.

## Acceptance criteria

- [ ] Packaged apps launch and capture/search/copy with no dev server or network dependency.
- [ ] Native helpers use the actual packaged app paths and Windows process identity, and helpers/modules load on Windows x64.
- [ ] Unsigned development status and remaining release qualification are explicit; unsigned test builds are not described as production-ready.

## Verification

Extend the existing canonical public functional service flow only where needed; keep real internal services/storage and fake external OS/time boundaries. Run strict types, ESLint, Prettier, functional tests and Windows packaging. UI, native delivery, NVDA, installation and performance requirements are manual Windows release checks where relevant. No automated GUI/E2E suite, duplicate flow tests, stress gates or new test infrastructure.
