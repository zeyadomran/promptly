# P18: Implement tag creation, filtering, and the reusable multi-select picker

Reuse one accessible tagging workflow across compact, regular, and keyboard entry points.

## Scope

- Normalize tag names with trimming and documented case folding; enforce case-insensitive uniqueness and lowercase display with deterministic palette cycling.
- Build searchable Command-in-Popover multi-select with create-if-missing, selected checks, keyboard support, and a shared tag repository.
- Connect Compact +, Regular New tag, preview Add tag, and Cmd/Ctrl+T; remove associations through badge × without row-copy propagation.
- Keep tag chips/counts and AND filtering synchronized after capture, edits, and assignments; leave tagging out of capture toasts.

## Acceptance criteria

- [ ] All creation paths enforce the same uniqueness and palette rules.
- [ ] Creating/assigning/removing tags refreshes both layouts and Settings counts.
- [ ] Focus returns to the trigger and picker Enter/Esc do not copy or hide the library.

## Verification

Case-collision/concurrent-create repository tests and full picker keyboard/assignment/filter tests.
