# P18: Implement tag creation, filtering, and the reusable multi-select picker

Reuse one accessible tagging workflow across compact, regular, and keyboard entry points.

## Scope

- Normalize tag names with trimming and documented case folding; enforce case-insensitive uniqueness and lowercase display with deterministic palette cycling.
- Build searchable Command-in-Popover multi-select with create-if-missing, selected checks, keyboard support, and a shared tag repository.
- Connect Compact +, Regular New tag, preview Add tag, and Cmd/Ctrl+T; remove associations through badge × without row-copy propagation.
- Keep tag chips/counts and AND filtering synchronized after capture, edits, and assignments; leave tagging out of capture toasts.

## Acceptance criteria

- [ ] All creation paths enforce the same uniqueness and palette rules.
- [ ] Creating/assigning/removing tags refreshes both layouts and Settings counts.
- [ ] Focus returns to the trigger and picker Enter/Esc do not copy or hide the library.

## Verification

One canonical public picker flow uses real owned SQLite, including concurrent case reuse, embedded-NUL identity, membership counts/AND results, database reopen and delayed target/clear outcomes. Strict checks and supported-OS package CI accompany it. Keyboard, focus, IME, theme/CSP and assistive-technology behavior require manual release qualification under the current functional-only test policy.

## Implementation status

Compact + and Cmd/Ctrl+T use the same searchable picker. Catalog mode creates tags and chooses AND filters; snippet mode immediately persists multi-select membership changes. Regular New tag/Add tag and badge removal consume the shared provider ports in P16; Settings tag management remains P20. No tagging is added to capture toasts.

Names use trim plus JavaScript's locale-independent Unicode lowercase, with a 64-UTF-16-unit limit after normalization and rejection of lone surrogates. Existing SQLite NOCASE uniqueness remains authoritative; it is not Unicode normalization or a new collation.
