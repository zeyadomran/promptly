# Tags

Tags organize snippets and queued prompts without changing their text. Library tag chips
filter results; the snippet's tag picker changes its membership. A composer also lets you
assign tags before saving to either destination.

## Assign tags

1. Select a snippet, then use **Add tag** in Regular view or the configured tag shortcut
   (**Ctrl+T** by default).
2. Applied tags appear first when the picker opens. Find a tag and select it to assign or remove it.
3. To create one, enter a new name and choose the offered creation action.

Library tag controls also let you find filters, clear filters with **All**, or show **Untagged**
snippets. Creating a tag from a library filter control creates a catalog tag; use the snippet
picker to assign it to a snippet.

Each library row shows up to five tag-color segments. A snippet with more than five tags shows
four tag colors plus a neutral segment. Tag names that do not fit appear as a `+n` count;
this label does not open a menu, and clicking the row copies the snippet. Select the snippet
and use the configured tag shortcut (**Ctrl+T** by default) to see or edit all assigned tags.

## Manage the catalog

Open **Settings → Tags**. Choose **New tag** to create a name and color, or use a tag's
Edit and Delete controls.

Names are trimmed and saved in lowercase. To recolor a tag, choose its **Edit** control and
select a preset swatch, or click the chip showing its hex color to open the custom-color popover.
Enter **Custom hex color** as `#` followed by six hexadecimal digits, then choose **Apply color**
or press **Enter**. **Escape** closes the popover without applying its draft. Finally choose
**Save tag** to save the tag; applying a color only changes the open tag editor's draft.
An existing name cannot be reused for a separate tag; choose a different name.

Deleting a tag removes it from snippets and queued prompts while keeping their content.
Tag deletion cannot be undone; review the confirmation before applying it.
