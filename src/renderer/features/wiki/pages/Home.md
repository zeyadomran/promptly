# Promptly

Compose, capture, organize and reuse text with managed attachments. Promptly is a local-first
Windows app with a reusable Library and a separate prompt Queue.

Create snippets and queued prompts directly, or capture selected text from a supported app.
Search and tag your Library, draw or annotate images, fill reusable variables for one copy,
and review ordered context bundles. Copy and return is explicit; Promptly never pastes for you.

This guide describes the **1.1.0** workflows. The download link opens published releases;
check the installer version and its release notes for feature availability.

**[Download Promptly for Windows x64](https://github.com/zeyadomran/promptly/releases)**
· [Release notes and other versions](https://github.com/zeyadomran/promptly/releases)

Run the installer, open Promptly from Start, and follow the first-launch walkthrough.
See [Getting Started](https://github.com/zeyadomran/promptly/wiki/Getting-Started) for setup and your first snippet.
If your installed version shows different controls, check the release notes and
[update guidance](https://github.com/zeyadomran/promptly/wiki/Settings).

Promptly targets Windows x64, with Windows 11 as the primary development environment.
Windows 10 compatibility remains manually unqualified; macOS, Linux, x86, and ARM64 are unsupported.
Actual capture depends on the source application's Windows UI Automation provider.
Clipboard capture fallback is deferred. See [capture limits](https://github.com/zeyadomran/promptly/wiki/Capturing-Text).

## Help inside Promptly

The app has a separate built-in **Wiki** that works offline. Open it from the title bar's
book icon, **Settings → About → Open wiki**, or **F1** when that key is not assigned to
another command. The in-app guide's project links and **Edit on GitHub** open your browser
and require a connection.

Read the [Privacy Policy](https://github.com/zeyadomran/promptly/blob/main/PRIVACY.md) for
local storage, capture, updates, and information you choose to share.
