# Home

Capture, organize, and reuse text snippets with a shortcut. Promptly is a local-first Windows app.

Select text in a supported application, press your capture shortcut, and find it later in your
library. Organize snippets with colored tags, search the full saved text, and copy it when needed.

Promptly currently supports Windows x64. Published Windows installers are available on the [Releases page](https://github.com/zeyadomran/promptly/releases).
Installer builds are unsigned; Windows may show a security prompt. Actual capture depends on the source application's
Windows UI Automation provider. Clipboard capture fallback and other platforms are deferred.

[Source code and project information](https://github.com/zeyadomran/promptly)

This guide is bundled with your app and works offline. Open it from the title bar,
[Settings → About](promptly:settings/about), or F1 when no configured shortcut uses F1.
Project links and Edit on GitHub open your browser and require a connection.
